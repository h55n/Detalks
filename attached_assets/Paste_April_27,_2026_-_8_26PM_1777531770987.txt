# DeTalks' 

## Project Overview

Build the complete, pixel-perfect **mobile frontend** for **DeTalks'** — a three-tier mental wellness platform built for India. This is a React Native (or React with mobile-first responsive design) application. The app must feel like the safest, warmest room someone has ever walked into. Every design decision must reduce anxiety, not create it.

**Stack:** React Native with NativeWind (Tailwind) OR React (mobile-first, max-width 430px, phone viewport). Use whichever the platform supports best. All UI must look and feel like a native iOS/Android app.

**Fonts (Google Fonts — import both):**
- `DM Serif Display` (weight 400, 400 italic) — all headlines, display text, emotional moments
- `DM Sans` (weights 300, 400, 500, 600) — all body text, UI labels, buttons

**Do NOT use:** Inter, Roboto, Arial, SF Pro, system fonts, or any other font family anywhere in the app.

--shadow-modal: rgba(100, 70, 30, 0.18) 0px 16px 64px;

**Global rules:**
- Page background is ALWAYS `#F5EFE6` (Warm Sand) — never white, never gray
- Cards are ALWAYS `#FAF6F0` (Warm Ivory) — lifting off the sand
- Shadows are ALWAYS warm amber-brown tinted — never cool gray or pure black
- Minimum border-radius on any interactive element: 8px — non-negotiable
- One primary (Forest Green) button per screen — never two
- Gold (`#F5C518`) is NEVER used for navigation, headers, or regular CTAs
- All animations must respect `prefers-reduced-motion`

## ANIMATIONS — IMPLEMENT ALL OF THESE

### 1. Breathing Canvas (Home background)
Extremely subtle radial pulse on the Warm Sand background:
- Cycle: 8 seconds
- Opacity oscillates: `#F5EFE6` → `#EDE7DC` at center, 2% shift
- Barely perceptible — felt, not seen

### 2. Screen Transitions
All screens fade in + translateY(8px → 0), 500ms cubic-bezier(0.4, 0, 0.2, 1). Nothing slides or slams.

### 3. Disha Typing Pulse
Three dots, 2000ms cycle, Sand Text color. Label reads `"Listening..."` not `"Typing..."`.

### 4. Card Lift
On hover/press: cards lift 4px (translateY -4px), shadow deepens from shadow-whisper to shadow-gentle, 350ms ease-in-out.

### 5. Session Closing Animation
Chat area fades to Warm Sand overlay, 1000ms. Centered DM Serif Display text appears: `"This conversation has been saved to your journey."` No abrupt cut.

### 6. Milestone Gold Flash
On milestone unlock: a single concentric gold ring pulses outward from the milestone element once. Not twice. Not three times. Once — like a bell struck once. `rgba(245,197,24,0.6)` → `rgba(245,197,24,0)`, scale 1.0 → 1.8, 600ms ease-out.

### 7. Micro-Practices Breathing Circle
Forest Green circle: inhale 4s expand, hold 2s, exhale 6s contract. No text during the cycle — only phase label fades in/out. No other UI.

### 8. Quick-Reply Chips Appear
Staggered fade-in from below, 80ms offset per chip, 300ms each.

### 9. Reduced Motion
All animations wrapped in `@media (prefers-reduced-motion: reduce)` — fallback to instant opacity transitions only, no movement, no scale.
